# MD Nazimul Haque — Personal Website

A responsive, static personal portfolio website designed for GitHub Pages.

## Deploy to GitHub Pages

1. Create a GitHub repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload all files and folders from this project to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

The CV is included at `assets/MD_NAZIMUL_HAQUE_CV.pdf`.

## Personalize

- Replace the `NH` avatar with a real profile image if desired.
- Update any text or project descriptions in `index.html`.
- Update links in the contact and hero sections.
